## FixFlow – Technician Job Management System

FixFlow is a web-based Technician Job Management System designed to simplify and improve the process of managing repair and maintenance services. It connects customers, technicians, and administrators through a single platform.

Customers can request services, select preferred technicians, and track job progress. Technicians can manage assigned jobs, update their work status, and view service requests. Administrators can manage users, approve technician registrations, assign jobs, and monitor overall activities.

Main Objective: To reduce manual work, improve communication, organize service requests, and make technician service management faster and more efficient.
